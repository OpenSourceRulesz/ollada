VRAM and speed were measured through Ollada's own code on the hardware named on each model's page (GPU shelf: Colab Tesla T4, 2026-10-21; sdar:1.7b: a laptop CPU, 2026-10-23 — single-run samples, treated as measured floors, not laws). The three GPU models were re-verified on a desktop RTX 5060 Ti on 2026-10-25; those peaks are the second VRAM column and the desktop notes on each model's page. Weights come from Hugging Face — Ollada hosts no registry.
