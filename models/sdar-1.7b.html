Verification notes

Verified on CPU through ollada's own adapter (feat/sdar-cpu load path: bf16, no device_map, tensor mask contract — this repo's modeling is the pre-rename revision, so the adapter's LossKwargs alias and flash_attn SDPA stand-in both engage; see adapters/sdar.py). Fixed prompt set at recipe defaults, all correct: train-speed reasoning (90 km/h, 21.2s), one-word capital probe (exactly 'Paris', 1.9s), Fibonacci code (clean and runnable, 6.3s) — gen_length 128. The 2-step reduced config FAILS at this size (capital never commits, fib garbles): 4 steps is the floor, matching SDAR's paper protocol. No vram_gb: this verification used no GPU. GPU verification not yet run.
Ollada — the shelf for open-source diffusion language models. Local-first, $0 project: no telemetry, no hosted registry — models come from Hugging Face, recipes are verified here. Every number on this site was measured by a real-load run on the hardware named.
