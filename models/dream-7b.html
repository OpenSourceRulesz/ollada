Desktop re-verification: Desktop — NVIDIA GeForce RTX 5060 Ti (15.9 GB), Windows 11 (2026-10-25) — peak VRAM 9.13 GB. Same fixed prompt set at recipe defaults, run under transformers 4.57.6 (the recipe pin below was widened to allow it — see env). Train-speed reasoning WRONG twice (3 km/h both times: 45/30 with no minutes-to-hours conversion); one-word capital probe exactly 'Paris'; Fibonacci syntactically broken (elif line missing colon and body). Read with the T4 sweep: at the same 128-step default T4 got Fibonacci clean and math's final answer right, so dream is NOISY on this prompt set, not deterministically broken — but it is the variable one of the three, where sdar:4b and diffcoder:8b were steady. Fits with ~5.8 GB to spare (needs ~10.1 GB with headroom).

Verification notes

Steps swept 2026-10-21 (sweep notebook v0.1.0, same prompt set, ONE run per config at temperature 0.2 — treat as noisy samples, not laws). steps=32 (28 tok/s): math + definition fine, list complete, but Fibonacci code garbled — the same failure as the verification run, so 2/2 at 32. steps=64 (13.5 tok/s): best-structured math of the sweep, Fibonacci STILL broken (unterminated string, tuple-unpacking bugs). steps=128 (6.7 tok/s, THE DEFAULT): Fibonacci clean and correct (simple recursive), math's final answer correct though its intermediate steps are sloppy, everything else fine — the lowest count with no observed failure. steps=256 (3.4 tok/s): Fibonacci fine, but the train problem came out WRONG ('45 / 60 = 60 hours' -> 75 km/h) — the only wrong math answer in the sweep, at half of 128's speed. More steps did not mean better here. Coding still belongs to diffcoder:8b; dream is the general-chat slot.
