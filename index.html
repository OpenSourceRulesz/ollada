Diffusion models, verified and ready to run

Ollada is the shelf for open diffusion models — curated names, verified recipes, one command, running locally on your GPU — or, for the SDAR models, your CPU. The same idea Ollama proved for autoregressive models, rebuilt for diffusion.

$ pip install "ollada[cpu]" # laptop, no GPU needed
$ ollada pull sdar:1.7b
$ ollada run sdar:1.7b

Why a shelf?

Diffusion models on Hugging Face ship with incompatible generation code, undocumented defaults, and no promise that the recipe on the card actually runs. Ollada wraps each model family in a tested adapter, bakes the verified defaults (steps, block size, quantization) into a recipe, and serves it behind an Ollama-shaped API — so tools that already speak Ollama can point at port 11435.

Ollada — the shelf for open-source diffusion language models. Local-first, $0 project: no telemetry, no hosted registry — models come from Hugging Face, recipes are verified here. Every number on this site was measured by a real-load run on the hardware named.
